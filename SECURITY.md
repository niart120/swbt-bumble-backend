# Security policy

## Supported versions

Security fixes are provided for the latest crates.io release. Older `0.x`
releases may require upgrading to receive a fix.

## Reporting a vulnerability

Use GitHub's
[private vulnerability reporting](https://github.com/niart120/swbt-bumble-backend/security/advisories/new)
for suspected vulnerabilities. Do not include adapter identifiers, link keys,
USB serial numbers, or other credentials in a public issue.

Include the affected crate version, operating system, adapter model, minimal
reproduction steps, and the security impact when those details can be shared
safely. Receipt and remediation timing depend on the report's scope and are
coordinated in the private advisory.
